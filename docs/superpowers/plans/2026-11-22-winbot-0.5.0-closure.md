# winbot 0.5.0 收口与审查计划

> **给执行者：** 每个任务先做/先测，再勾。结论必须来自命令输出，不写「应该可以」。

**目标：** 把 0.3.3 → 0.5.0 这段（自动路由、团队包、应用连接、新界面、自动更新、手机访问）收成可回归、可追溯、文档与代码一致的状态。

**架构：** 不变。`src/` 主进程 + `src/dsh-plugins/` 注入 DSH 子进程 + `ui/` 原生 ESM + `electron/` 桌面壳；所有对外能力走本机 HTTP + 令牌。

**技术栈：** Node 24 ESM、`node:sqlite`、DSH SDK over stdio、Electron 44.11.5、electron-builder(NSIS)、ComfyUI 0.45、`qrcode`（后端生成二维码）。

**规格来源：** `docs/FEATURES.md`、`CHANGELOG.md`、`docs/compare-openmausbot.html`。

## 基线（2026-11-22 23:40）

- 版本 `0.5.0`；`git status` 干净；HEAD `b24bd71`。
- Release：`v0.4.0`、`v0.5.0`，各带 `winbot-Setup-*.exe`。
- 测试：`test/` 57 个脚本；快检 4 项、`--model` 18 项、`--ui` 5 项。
- 已知缺口：远程公网、代码签名、CI、3D 贴图、多语言。

## 全局约束

- 不改 DSH 安装目录；定制只在本仓库与生成的 patch。
- 生成类（图/视频/3D）默认不进回归。
- 涉及安全（令牌、局域网）必须实测无 token 被拒。
