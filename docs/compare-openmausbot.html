winbot 更强的地方

  • 本机生成：Z-Image 生图、MiniMax H3 生视频（滑窗长镜头 / 首尾帧）、Hunyuan3D 生 3D——OpenMausBot 完全没有。
  • 渠道接入：Telegram / Slack / Discord 都能用；OpenMausBot 是「自己的 app + 手机 web」，不接第三方 IM。
  • 中文与本地化：界面、技能、审批全中文；对国内模型接口（DeepSeek 等）开箱可用。
  • 分寸感：按机器人的每日预算、免打扰、每日上限、失败暂停、送达队列——这些 OpenMausBot 的 routines 没有那么细。
  • 可看生成过程：右侧内嵌 ComfyUI，出图/出片时能盯着队列。

OpenMausBot 更强的地方

  • 跨平台 + 签名：macOS/Windows/Ubuntu 都有安装包，macOS 签名公证；winbot 只有 Windows 且未签名。
  • 应用生态：Composio 500+ 应用（Gmail/Slack/GitHub/Notion…）+ 应用事件触发；winbot 只有自建 MCP。
  • 云电脑 / 隔离 VM：每个 bot 一台云端 Linux 桌面或本地 VM；winbot 只有本机桌面（需审批）。
  • 手机与远程：原生 App、配对、Tailscale 打开另一台电脑的 bot；winbot 现在只有同 WiFi 的浏览器访问。
  • 语音：TTS（ElevenLabs/Fish/Grok/Mac 本地）、通话、听写；winbot 没有。
  • 团队模板 / 分享：一个 Markdown 装一整套团队；能把自己发布出去；winbot 只能一个机器人一个机器人建。
  • 自动化更宽：webhook + 应用事件 + 自动路由（Jev）；winbot 只有定时 + @/上一个发言。
  • 对外接口：自带 stdio MCP server 给 Claude Desktop/Cursor，另有 headless CLI；winbot 只有本机 HTTP API。
  • 工程规格：TypeScript strict、pnpm test（unit/driver/API/desktop）、SBOM；winbot 是纯 JS + 自建回归脚本。

如果只抄三件事

  • 公网远程访问：现在只有同一 WiFi；接 Tailscale 或反代 + HTTPS 才能在外面用。
  • 手机/远程接入（配对 + Tailscale）：现在只能在跑它的那台电脑上用。
  • 托管的 OAuth 应用目录（Composio 等价）：已有 7 个 MCP 模板，但没有「点一下就用」的 OAuth 授权与凭据托管。

语音 TTS、团队模板、webhook 是第二批；云电脑涉及付费第三方，短期不建议跟。
