# winbot 功能清单

> 更新时间：2026-11-22 · 版本 0.2.0
> 标记：✅ 已实现并实测 · 🟡 已实现但有前提/没实测 · ⛔ 没做

## 一、已经有的

### 1. 内核与安全

| 状态 | 能力 | 说明 |
|---|---|---|
| ✅ | 多机器人 | 每个机器人独立的人设、默认模型、工作区、记忆、权限 |
| ✅ | **双内核：DSH / Codex** | 每个机器人可选内核；Codex 走 `codex exec`，独立 `CODEX_HOME`，不碰用户的 `~/.codex` |
| ✅ | 三档权限 | 只读 / 工作区（默认）/ 完全；越界写会停下来问你 |
| ✅ | 审批落库 | 审批卡片进会话、回答后状态持久化，重启作废（不会挂假待办） |
| ✅ | 工作区隔离 | DSH 沙箱真的限制在 `workspace/`，不是提示词里求它 |
| 🟡 | Codex 下的审批 | 沙箱在启动时定死，越界由 Codex 直接拒绝（更严），但不弹 winbot 审批卡 |
| ✅ | 单实例 + 崩溃自愈 | 桌面壳只跑一个；后端挂了 1.5s 内重启 |
| ✅ | 崩溃恢复提示 | 启动时给「没处理完」的会话补一条「麻烦重发」 |
| ✅ | 每日 token 预算 | 聊天和定时任务都算，超了直接拒绝并说明 |
| ✅ | 数据本地 | 会话、记忆、文件、Key 都在 `data/`（安装版在 `%APPDATA%\winbot\data`） |

### 2. 记忆

| 状态 | 能力 | 说明 |
|---|---|---|
| ✅ | 「关于我」共享记忆 | 跨机器人共享，4000 字上限 |
| ✅ | 敏感信息闸门 | 电话/邮箱/住址/证件要先问；密码/密钥一律拒记 |
| ✅ | 机器人自己记 | `remember` / `forget` / `recall_about_me` |
| ✅ | 记忆即时生效 | 记完下一轮就能用（进程自动重启带新提示） |
| ✅ | 手改记忆 | 机器人面板里能编辑人设和长期记忆 |

### 3. 聊天与呈现

| 状态 | 能力 | 说明 |
|---|---|---|
| ✅ | 应用内聊天 | 工具步骤实时显示、审批卡片、错误提示 |
| ✅ | **逐字输出** | 走 DSH 的 `llm/stream`，token 级增量（不是前端假装打字） |
| ✅ | 图片/文件输入 | 按钮、粘贴、拖拽；图片给模型看，其它文件进工作区 |
| ✅ | 交付文件 | `present` 的文件显示成可点开的卡片 |
| ✅ | 图片/视频内嵌 | 生成的图片直接显示，视频带播放器 |
| ✅ | 3D 文件卡片 | `.glb` 显示成 🧊 卡片（无内嵌预览） |
| ✅ | 用量显示 | 每条回复 ↑上下文 ↓输出；顶部累计 |
| ✅ | 聊天记录搜索 | 本机 LIKE 搜索，可按机器人过滤，点结果跳转（Ctrl+K） |
| ✅ | 流式渲染优化 | requestAnimationFrame 合帧，不每个 token 重画 |

### 4. 机器人的工具

| 状态 | 能力 | 说明 |
|---|---|---|
| ✅ | 读写文件 / 执行命令 | DSH 原生工具 + 沙箱 |
| ✅ | **技能** | 每个机器人一个技能目录，粘贴 SKILL.md 或导入 ZIP，模型自己调用 |
| ✅ | **团队包一键装** | 一段 Markdown/JSON 建多个机器人 + 群，同名更新不重建（见 `docs/team-format.md`） |
| ✅ | **连接器（MCP）** | 本地命令或远程 HTTP，工具以 `mcp__名字__工具` 出现 |
| 🟡 | **应用连接模板** | 7 个现成模板（filesystem/GitHub/Slack/Notion/Playwright/fetch/Postgres）一键接入；不是 Composio 那种托管 OAuth 目录 |
| ✅ | **电脑操作** | 截屏、看窗口（免审批）；点鼠标/打字/切窗口（默认每次问） |
| 🟡 | 电脑操作实机 | 只验证到「审批拦截」；没有真去动过键盘鼠标 |
| ✅ | **机器人互派** | `ask_another_bot`：交给另一个机器人，它用自己的权限/预算做完回结论 |
| ✅ | **群聊** | 一个群拉几个机器人，`@名字` 指定谁答；共享消息、各自独立上下文 |
| ✅ | **自动路由（谁该答）** | 没 @ 时按 `rules`（关键词/上一个发言）或 `model`（小模型挑人）决定，日志有理由 |
| ✅ | **停止这一轮** | 忙碌时输入框旁出现「停止」，掐断当前进程并留提示，之后还能继续聊 |
| ✅ | **审批记住一小时** | 审批卡可点「允许，1 小时内同类」，同类（写文件/命令/桌面/MCP）不再问 |

### 5. 生成（接本机 ComfyUI）

| 状态 | 能力 | 说明 |
|---|---|---|
| ✅ | **生图** | Z-Image Turbo（8 步）优先 / SDXL 兜底；1024² 约 25 秒 |
| ✅ | **生视频** | MiniMax H3，512²、39 帧带音轨，约 2 分钟 |
| ✅ | **生 3D** | Hunyuan3D 2.1，图→glb，约 80 秒，10 万+ 顶点；**纯几何，无顶点色、无贴图** |
| ✅ | **看它跑** | 生图/生视频/生 3D 时右侧自动打开 ComfyUI，能看队列和进度 |
| ✅ | 面板可拖拽 | 左缘拖动调宽、双击复位、宽度记住 |
| ✅ | 模型自检 | `media_status` 报告 ComfyUI 在线状态和已有模型 |
| ✅ | **自动更新** | 设置/托盘查 GitHub Releases；安装前自动退出应用，再静默安装（需 token） |
| ✅ | **登录态 Cookie** | 带 token 打开后 302 到干净地址，HttpOnly + SameSite=Strict；地址栏不留令牌 |
| ✅ | **手机访问（局域网）** | 设置里开启后同 WiFi 扫码使用；远程公网未做 |

### 6. 渠道

| 状态 | 能力 | 说明 |
|---|---|---|
| ✅ | Telegram | 文字、图片、文档；注入工作区；回复可发文件 |
| ✅ | Slack | Socket Mode |
| ✅ | Discord | Gateway |
| ✅ | Telegram 群聊 | 群里只在 `@机器人`、回复它、或发命令时接；群共享一条会话（不同人同群同上下文） |
| ✅ | Slack / Discord 频道 | 频道里只在被 @ 或发命令时接；私聊照常 |
| ⛔ | 飞书 | 需要企业自建应用（App ID/Secret + 事件订阅 + 卡片权限） |
| ⛔ | 微信 | 个人号没有官方接口；桥接有风控风险 |

### 7. 定时任务与送达

| 状态 | 能力 | 说明 |
|---|---|---|
| ✅ | 定时任务 | 每天/每周/间隔；观察模式（真只读） |
| ✅ | 预算 | 单次 / 每月 token 上限，超了暂停 |
| ✅ | 免打扰 | 夜里排队，到点再送 |
| ✅ | 每日上限 | 每个渠道每天最多几条 |
| ✅ | 失败暂停 | 连续 3 次失败自动暂停，附原因 |
| ✅ | 送达队列 | 先落盘，超限合并，失败指数退避重试 |
| ✅ | `[安静]` 约定 | 没什么可说就不打扰 |

## 二、还没做的

按「阻塞点」分类，不按重要性。

### A. 缺凭据/资质（我这边做不了）

| 状态 | 事项 | 卡在哪 |
|---|---|---|
| ⛔ | 飞书渠道 | 需要你建企业自建应用，给我 App ID/Secret + 事件订阅 |
| ⛔ | 微信渠道 | 个人号无官方接口；iLink/扫码桥接或客户端 UI 自动化，有风控 |
| ⛔ | Tripo 3.1 | 权重不开源，只能调云端 API，需要 Tripo/Comfy 的 key |
| ⛔ | 代码签名 | 需要购买证书（否则一直会有 SmartScreen 提示） |

### B. 缺模型/资源（可以下，但体积大）

| 状态 | 事项 | 成本 |
|---|---|---|
| ⛔ | 3D 带贴图 | 需要 Hunyuan3D paint 模型（约 6 GB）。试过 BakeTextureFromVoxel / PaintMesh，都因体素没有颜色数据失败（见 PROGRESS） |
| ✅ | 更长视频 | 单段 >39 帧自动走滑窗（90 帧 ≈155 秒，无接缝）；多段 chain = 末帧锚到下一段首帧 + 音频 AudioConcat；`cut` 为硬切 |
| ✅ | 首尾帧控制 | `first_frame` / `last_frame` 锚定首末画面（实测逐像素一致） |
| ⛔ | 语音转写 | 需要 STT 模型/服务；现在 Telegram 语音只当文件存 |

### C. 明确没做（可以排期）

| 状态 | 事项 | 说明 |
|---|---|---|

| ⛔ | 多语言 | 界面只有中文，词条没抽 |



| ⛔ | 远程公网访问 | 现在只有同一 WiFi；公网要 Tailscale 或反代 + HTTPS |
| ✅ | **会话导出** | 历史会话可导出 Markdown（时间/发言人/附件） |
| ✅ | **数据备份/恢复** | 托盘导出 zip（库+工作区+配置+令牌），恢复时先留底、失败回滚 |
| ⛔ | 3D 内嵌预览 | 需要 `model-viewer` 之类的库；现在是文件卡片 |
| ⛔ | 工具级权限面板 | 现在只有「只读/工作区/完全」三档，不能按工具细控 |
| ⛔ | 定时任务链式/依赖 | 现在每条独立，不能「A 完了再 B」 |
| ⛔ | 机器人主动找人 | 只有定时任务能主动发；没有「它觉得该找你」的机制 |

### D. 已知的粗糙点（不算没做，但该改）

| 状态 | 问题 |
|---|---|
| ✅ | 群聊认人按名字，新建时已禁止重名（409） |
| 🟡 | 安装目录 945 MB（DSH 依赖大 + 关了 asar） |
| 🟡 | 8G 显存下视频/3D 都靠卸载换页，速度受限；Z-Image→3D 需要手动释放显存 |
| 🟡 | 面板打开时中栏会变窄，聊天头会换行（已缓解，不算优雅） |
| ✅ | 机器人回复统一用工作区相对路径（0.3.0 在系统提示里约束） |

## 三、如果继续，我的建议顺序

1. **停止本轮 + 审批记住一小时**（日常最痛的两个摩擦点，改动小）
2. **渠道内群聊**（Telegram 群 `@` 机器人），比再堆生成能力更实用
3. ~~自动更新~~（0.4.0 已做：设置/托盘查 GitHub Releases）
4. 3D 带贴图 / 长视频（要下模型，随时可做）
